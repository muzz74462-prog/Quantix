# QUANTIX

Phase 1: public landing page (Next.js + TypeScript + Tailwind CSS).

## Run

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build
npm run typecheck  # tsc --noEmit
```

The trading terminal on the landing page is a visual mock-up with sample data. It cannot execute trades.
